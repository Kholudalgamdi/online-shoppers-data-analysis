# تحليل بيانات المتسوقين عبر الإنترنت

هذا المستودع يحتوي على مهمة تحليل بيانات تم تنفيذها ضمن **معسكر Hash Plus** باستخدام Microsoft Excel.

## وصف المهمة

تهدف المهمة إلى تطبيق أساسيات تحليل وتنظيف البيانات على مجموعة بيانات لسلوك زوار متجر إلكتروني، بدايةً من فهم البيانات وفحص جودتها، وصولًا إلى تحليلها واستخراج ملاحظات أولية منها.

## ما تم تنفيذه

- إنشاء قاموس للبيانات يوضح معنى ونوع كل عمود.
- فحص جودة البيانات باستخدام `COUNTA` و`COUNTBLANK` و`MIN` و`MAX` و`ISTEXT`.
- فحص القيم المفقودة والتكرارات وأنواع البيانات والقيم غير المنطقية.
- اكتشاف وحذف **125 صفًا مكررًا**.
- انخفاض عدد السجلات من **12,330 إلى 12,205 سجلًا** بعد التنظيف.
- استخدام الذكاء الاصطناعي لاقتراح خطة لتنظيف البيانات والتحقق من الاقتراحات في Excel.
- مقارنة جودة البيانات قبل التنظيف وبعده.
- استخدام PivotTable للإجابة عن سؤالين تحليليين.

## أبرز الملاحظات الأولية

- سجل **الزوار العائدون (Returning Visitors)** أعلى عدد من عمليات الشراء بواقع **1,470 عملية**.
- سجل **شهر نوفمبر (Nov)** أعلى عدد من عمليات الشراء بواقع **760 عملية**.

## الأدوات المستخدمة

- Microsoft Excel
- PivotTable
- الذكاء الاصطناعي كمساعد في اقتراح ومراجعة خطوات تنظيف البيانات

## ملاحظة

تم تنفيذ هذا العمل لأغراض تعليمية ضمن متطلبات **معسكر Hash Plus**.
